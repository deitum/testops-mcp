## TC-01. Оформление заказа: успешный переход к оплате

### Описание
Проверка, что покупатель с товаром в корзине может оформить заказ и дойти до выбора способа оплаты.

### Предусловия
- Открыта витрина интернет-магазина.
- Покупатель авторизован под учётной записью buyer1.
- В корзине один товар, он есть в наличии.
- Для покупателя сохранён адрес доставки address1.
- Для покупателя доступен способ оплаты card1.

### Шаги
```
[step 1] Открыть корзину
	[expected 1.1] Корзина открыта
	[expected 1.2] Ошибки загрузки не отображаются

[step 2] Нажать кнопку Оформить заказ
	[expected 2.1] Открылась форма оформления заказа

[step 3] Выбрать доставку курьером
	[expected 3.1] Открылась страница параметров доставки

[step 4] Заполнить параметры доставки
	[step 4.1] Указать адрес доставки address1
		[expected 4.1.1] Адрес доставки выбран
	[step 4.2] Отметить чекбокс Данные проверены
		[expected 4.2.1] Чекбокс отмечен

[step 5] Перейти к выбору способа оплаты
	[expected 5.1] Открылся шаг выбора оплаты
```
